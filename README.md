# Lēkam 108 — числовой квадрат и чакрабандхи

Исследовательский офлайн-инструмент к научной работе о комбинаторном стихосложении на основе
пандиагонального «наисовершеннейшего» (most-perfect) магического квадрата с константой **108**
и двух старотамильских чакрабандх (Nāṉkārai Cakkarapantam и вторая, vā…vā).

Цель — выявить «следы мозга программиста-комбинаторика»: строгие инварианты конструкции, которые
нельзя получить случайно, и проверить наличие шифра/логики построения между квадратом и чакрабандхами.

## Запуск (офлайн)

```
python3 -m http.server 7914 --directory ~/lekam108
```
Открыть <http://localhost:7914>. Один самодостаточный файл `index.html` (шрифт Jaipur встроен,
внешних зависимостей нет). Стиль — дизайн-система goroskop1008.ru.

## Модули

| Вкладка | Что делает |
|---|---|
| **Квадрат** | Интерактивный квадрат 4×4; подсветка семейств узоров (строки, столбцы, пандиагонали ╲╱, блоки 2×2, квадранты, углы); свойства; бустрофедонное разворачивание 4×8. |
| **Комбинаторика · 72** | Все 4-элементные наборы чисел {1–8, 46–53} = 108. Классификация: 28 «две доп. пары 54+54» + 44 прочие. Сверка с 32 геометрическими паттернами. |
| **Чакрабандхи** | Обе чакры в виде колеса: 4 квадранта, рефрен-рамка **vā**, порядок чтения по спирали, слова после сандхи с глоссами. |
| **Отрезок (в Чакрабандхах)** | Выбор 1–5 кружков на колесе → подбор тамильских слов из проверенного лексикона (104 статьи) с учётом падежей (-ai, -āl, -ku, -il, -iṉ, -ōṭu, -ē, -ā, -um, -kaḷ), метрических долгот, усечений конечных согласных, звательного и **санскритского/архаичного чтения**; граммсправка и санскритская этимология; варианты чтения отрезка по частям; кнопка «Анализ ИИ» (Claude, Anthropic API — ключ хранится только в браузере). |
| **Уровни сопоставления** | 1) точная форма → 2) падеж → 3) метрич. долгота → 4) санскр./архаичное чтение. Нормализация: ś↔c, ṉ↔n. Санскр. фолдинг: b/bh/ph→p, g/gh/kh→k, d/dh/th→t, j/jh→c, ḍ/ḍh→ṭ, ś/ṣ/s→c, r↔ṟ, n/ṉ/ṇ, ḷ/l, снятие висарги; протеза i-/u- перед r-/l- (rāya→irāyaṉ); глайд-сандхи (снятие вставных y/v). Ретрофлексные ṇ/ḷ различают значения на точном уровне, но приравниваются на санскр. уровне. |
| **Научная справка** | В той же вкладке: 15 правил адаптации санскрита в тамильском (тадбхава/татсама) + 18 тезисов о мантрических и композиционных конвенциях чакрабандхи (панчакшара, катапаяди, бустрофедон, шаговое чтение gūḍha, числовой символизм 108/54/27). |
| **Лаборатория** | Число ↔ позиция ↔ слог. Карта «число → слоги»; показывает, что подстановочного шифра нет (числа отображаются в несколько слогов), а рамочные {46,48,51,53} → **vā**. |
| **Переводчик** | Точечный тамильский декодер (ISO 15919): глоссарий, правила сандхи, деепричастие, звательный падеж. Источник: Tamil Lexicon, Univ. of Madras. |

## Подтверждено расчётом

- **72** набора из 4 чисел = 108 (совпадает с ручным подсчётом): 28 комплементарных + 44 прочих.
- **32** геометрических паттерна = 108 (4 строки + 4 столбца + 8 пандиагоналей + 16 блоков 2×2) —
  квадрат пандиагональный и most-perfect.
- 8 дополнительных пар по 54; 108 = 2×54.
- Числа-рамки {46, 48, 51, 53} в совмещённой сетке 4×8 всегда стоят на позиции рефрена **vā**.

## На проверку (данные оцифрованы из диаграмм автора)

- Диакритика слогов обеих чакрабандх (ISO 15919) — объекты `CHAKRA1` / `CHAKRA2` в `index.html`.
- Квадрант ④ Чакры II, 5-й слог: читается как `lai(?)` — буква на инскрипции плохо читается,
  долгий гласный структурно невозможен (прежнее чтение `vī` исключено). Варианты перебираются;
  в интерфейсе слог помечен «?» и пунктиром.
- Глоссарий `GLOSSARY` и правила `SANDHI_RULES` — черновые, требуют сверки перед публикацией.

## Лексикон отрезков (`WORDS` в `index.html`)

104 статьи. Ядро — 64 слова, собранные ИИ-агентами по всем слоговым n-граммам (1–5 слогов)
обоих колёс и проверенные двумя скептиками (существование/письмо и русские значения).
Второй слой — 40 санскритизмов, царской/эпической лексики и мантрических форм: собраны
по правилам адаптации санскрита в тамильском (тадбхава/татсама) и мантрическим конвенциям,
отобраны с учётом вердиктов трёх скептиков (форма / значение / санскр. этимология).
У санскритизмов заполнено поле `skt` — источник в IAST. Источники: Tamil Lexicon
(Univ. of Madras), «Тирумантирам», «Тандияланкарам».

> Примечание: часть тройной проверки санскритизмов не завершилась из-за лимита сессии
> и была докручена вручную (Opus 4.8) по завершённым вердиктам и словарям. Это черновой
> исследовательский инструмент — сверяйте статьи с бумажным словарём перед публикацией.

## Данные (для правки — в `index.html`, секция «ДАННЫЕ»)

- `SQUARE` — квадрат 4×4.
- `GRID8_NUM` / `GRID8_SYL` — совмещённые сетки 4×8 (числа и слоги Чакры I).
- `CHAKRA1`, `CHAKRA2` — квадранты и слова после сандхи.
- `GLOSSARY`, `SANDHI_RULES` — словарь и правила чтения.
